# 📚 Library Management System

A C++ based Library Management System for managing books, students, book issue and return records.

## 🚀 Features

- 📖 List of Books
- 📚 Purchase Books
- 📕 Issue Books
- 🔄 Return Books
- 📋 Issued Books Details
- 📋 Returned Books Details
- 🔍 Query by Student
- 🔎 Query by Book
- ✏️ Modify Book Records
- 🗑️ Delete Return Records
- 💰 Late Fine Details
- ℹ️ About Application
- 🚪 Exit

## 🛠️ Technologies Used

- C++
- File Handling
- Structures
- Classes & Objects
- Functions
- Console Interface

## 💾 Data Files

- `RECORD.DAT` - Book Records
- `BISSUE.DAT` - Issued Book Records
- `BRETURN.DAT` - Returned Book Records
- `FINE.DAT` - Fine Records

## 🎯 Objective

The objective of this project is to manage library books and student records using a simple menu-driven C++ application.
